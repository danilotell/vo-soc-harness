{# Self-contained on purpose. The report is archived as evidence and opened months later, sometimes on a segregated network: it must render with no network access, and it must not execute third-party code in the analyst's browser. Hence inline CSS, inline SVG, no CDN and no JavaScript. The layout is fixed; the content is not. Everything comes from the view model that `scripts/render_report.py` builds, so a field added or removed upstream changes the report without changing this file. To write your own template, bind to the same view model — `report.meta`, `report.timeline`, `report.indicators`, `report.impact`, `report.mitre`, `report.executed`, `report.extras` — and check it with: uv run --with jinja2 --no-project scripts/render_report.py --check-template #} {# Inline SVG and not an icon font or a sprite from a CDN: the report is archived and reopened offline, where anything fetched at load time is a broken glyph.
